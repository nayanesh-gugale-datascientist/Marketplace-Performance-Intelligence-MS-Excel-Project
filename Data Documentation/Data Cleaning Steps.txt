Part A: Power Query basics (explain once to students)

Open a new Excel workbook, save it in 03_Workbook, then go to Data tab → Get Data → From File → From Text/CSV.

Select the file and click Transform Data, not Load.
Inside the Power Query Editor, turn on the profiling tools: View tab → tick Column quality, Column distribution, Column profile, and Formula Bar.
At the bottom-left status bar, change “Column profiling based on top 1000 rows” to Column profiling based on entire data set. Otherwise your null and error counts will be wrong.
The right-hand Applied Steps pane is a recorded list of everything you do. Rename important steps by right-clicking → Rename (for example “Removed duplicate reviews”) so the step list reads as documentation.
When you finish a table, use Home → Close & Load To… → Only Create Connection + tick “Add this data to the Data Model”. Never load 100,000 rows onto a worksheet.

Part B: The universal cleaning checklist

Apply this to every table, in this order. Students should memorize it.

Profile: check row count, nulls, errors and distinct counts.
Rename the query (for example olist_orders_dataset → Orders).
Set data types (Date/Time, Decimal Number, Whole Number, Text).
Trim and Clean text: select columns → Transform → Format → Trim, then Clean.
Fix text case: states in UPPER, cities in Capitalize Each Word.
Handle nulls: decide to keep, fill, replace or remove, and log why.
Remove duplicates: select the key column → Home → Remove Rows → Remove Duplicates.
Check invalid values or outliers (negative prices, impossible dates).
Remove columns you don’t need.
Log it.
